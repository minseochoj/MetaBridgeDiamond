# MetaBridgeDiamond

MetaBridgeDiamond enables high-performance real-time data processing and auto-scaling, deploying scalable agents as a robust manager.

With MetaBridgeDiamond, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/MetaBridgeDiamond.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

MetaBridgeDiamond is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
